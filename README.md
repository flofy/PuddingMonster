# Pudding Monsters

Clone du jeu Pudding Monsters.

- **Version React** : branche main. Deployee sur GitHub Pages via GitHub Actions.
- **Version Rust (Bevy)** : branche [rust](https://github.com/flofy/PuddingMonster/tree/rust).

## React

pnpm install
pnpm run dev

Build : pnpm run build

## Rust

git checkout rust
cargo run
