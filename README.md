# Pudding Monsters (React)

A React version of the Pudding Monsters game.

## Features
- 5 worlds with 25 levels each (125 total levels)
- Special pudding types: Green (sticky) and Purple (telepathic)
- Star collection system
- World selection with unlocking mechanism

## Development

Run npm install then npm run dev

## Deployment

Run npm run build then npm run deploy for GitHub Pages
