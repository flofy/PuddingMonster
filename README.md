# Pudding Monster

This repository contains two implementations of the Pudding Monsters game:

- **Rust version (Bevy engine)**: See the [rust branch](https://github.com/flofy/PuddingMonster/tree/rust)
- **React version (TypeScript)**: See the [react branch](https://github.com/flofy/PuddingMonster/tree/react)

## Rust Version

To run the Rust version:

```bash
git checkout rust
cargo run
```

## React Version

To run the React version:

```bash
git checkout react
npm install
npm run dev
```

To deploy to GitHub Pages:

```bash
npm run build
npm run deploy
```
